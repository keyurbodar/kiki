# Coverage

## Bundle

All 299 token variables defined in Capy's production stylesheet are here: the 170 `@layer theme` variables, the default light and dark theme variables, the 26 responsive raw values (touch and desktop), the preset derivation and the 13 presets in light and dark, the preview and diff-palette overrides, and the font stacks. Tailwind's own `--tw-*` internals and lightningcss's `light-dark()` polyfill variables are not tokens and are left to Tailwind.

The bundle ships colour values twice, a plain fallback and a `color-mix()` value inside `@supports`. These files keep the `color-mix()` value, which is what every current browser renders.

## Motion sheet

The canvas Motion frame (pvdCpbOeDQ) lists 100, 120, 140, 150, 200, 300, 400 and 500ms. 150/200/300/500 are Capy's `--duration-fast/base/slow/slower`. 100, 120 and 140ms, and the other literal timings the bundle uses (110, 160, 192, 220, 240, 320ms, 1.1s, and the 40 to 250ms delays), are named in `motion.css` so feature code can reach them. The 400ms toast enter is sonner's own timing and stays inside sonner.
